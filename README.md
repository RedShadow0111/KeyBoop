# KeyBoop

Бесплатное меню-бар приложение для macOS: если слово набрано не в той раскладке, KeyBoop заменяет его и переключает раскладку. Русский и английский. Текст не уходит с компьютера.

`ghbdtn ` становится `привет `, раскладка переключается на русскую. В обратную сторону так же: `руддщ ` становится `hello `.

## Как пользоваться

- Обычное слово чинится на **пробеле**.
- Начало адреса (`https://`, `www.`) чинится сразу, не дожидаясь пробела.
- Регистр сохраняется: `Ghbdtn ` → `Привет `.
- **Двойной Shift** переводит последнее слово. Если автозамена только что ошиблась, тот же жест отменяет её и запоминает слово: во второй раз KeyBoop его не тронет.
- **Тройной Shift** переводит всю текущую фразу.
- Enter и Tab не переписываются: клавиша уже ушла в программу, и повторная отправка могла бы, например, отправить сообщение дважды.
- В полях пароля и в выбранных приложениях KeyBoop молчит. Сразу в списке Terminal и iTerm.
- Пока идёт замена и вы нажали свою клавишу, перепечатка обрывается.

Клавиатура не захватывается. Если KeyBoop зависнет, набор продолжится.

## Сборка

Нужны macOS 14 или новее и Apple Silicon (M1 и новее). Xcode не обязателен, хватает Command Line Tools.

```bash
git clone https://github.com/RedShadow0111/KeyBoop.git
cd KeyBoop
swift run KeyBoopSelfTest
./Scripts/package-app.sh
open dist/KeyBoop.app
```

`KeyBoop.app` подписан ad-hoc, без аккаунта Apple Developer. Если macOS не даёт открыть скачанный архив:

```bash
xattr -dr com.apple.quarantine /Applications/KeyBoop.app
```

Либо ПКМ по приложению → «Открыть».

При первом запуске нужны два разрешения: **Мониторинг ввода** и **Универсальный доступ**. Оба остаются на Mac, сеть приложению не нужна. После галочки в настройках иногда требуется выключить и включить KeyBoop в списке ещё раз: система привязывает доступ к подписи файла.

Автозапуск при входе включается в настройках уже у собранного `.app`.

## Как это устроено

KeyBoop слушает физические коды клавиш (`CGEventTap`, режим listen-only) и декодирует их и в текущей раскладке, и в другой через `UCKeyTranslate`, по тем раскладкам, которые стоят в системе. На пробеле словарь и символьные триграммы решают, какая сторона правдоподобнее. Замена — это Backspace и по одному символу Unicode, без буфера обмена. Раскладку переключает `TISSelectInputSource`.

Слово из словаря текущей раскладки не трогается. Если словарные оба варианта, слово тоже остаётся. Короче трёх букв не исправляется. Отдельно пропускаются цифры, camelCase, пути, почта и выученные исключения.

Проверка точности: `swift run KeyBoopSelfTest`. На отложенной выборке слов, которых не было в словаре при этой проверке, полнота не ниже 90%, ложных замен на тех же словах, набранных правильно, нет. Частый набор вроде «привет» и «hello» заменяется целиком.

## Ограничения

- Пара раскладок — русская и английская, уже добавленные в систему.
- Только arm64, macOS 14+.
- Служебные клавиши вроде стрелок сбрасывают буфер: после клика мышью жест Shift не должен стирать чужое место.
- Пока идёт перепечатка и приходит своя клавиша, уже отправленные символы не откатываются.
- Нет звука, сниппетов, транслита и правки опечаток.

## English

KeyBoop is a free menu-bar app for Apple silicon Macs. It rewrites a word typed in the wrong Russian/English layout and switches the layout, on device, with no network. Build with `./Scripts/package-app.sh`, then allow Input Monitoring and Accessibility.
